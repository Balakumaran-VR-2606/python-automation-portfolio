# Balakumaran VR — Portfolio Website

A responsive, no-build personal portfolio site. The main illustration and project visuals are embedded in the page/CSS, so there are no image files to download or configure.

## Preview locally

Open `index.html` in a browser. The site uses a Google Fonts stylesheet when online and falls back to system fonts when offline.

## Update contact links

Edit the email, phone, LinkedIn, and GitHub anchors in `index.html` if any of those details change. The email button opens a pre-addressed message; the phone link uses the device's call handler.

## Publish

This directory can be deployed as a static site with GitHub Pages or another static hosting provider. Check the displayed contact information and public portfolio content before publishing.
